# HNPSAC

---
In the Industrial Internet of Things (IIoT) environment, Mobile Edge Computing (MEC) enables effective reduction of transmission latency and central cloud load through task offloading. However, the dynamic and complex industrial scenarios still pose continuous challenges to system performance optimization. To address this, we propose a hybrid optimization framework named HNPSAC.

## Features
- **Task Offloading**: Models MEC scenarios, optimizing latency and cost trade-offs.
- **Simulation Framework**: Simulates IIoT environments with varying network speeds, server capacities, and workloads.
